## 🌌 Aperçu

**Rezo** est une page d'accueil haute performance pour bot Discord de qualité militaire, conçue avec une esthétique cyber futuriste. Avec des tons rouge néon et noir profond (`#0a0202`, `#1a0505`, `#dc2626`, `#ef4444`), des constellations interactives HTML5 à 60fps, des cartes à effet spotlight suivant la souris, et une architecture modale à la demande.

---

## ✨ Fonctionnalités Clés

### 🎨 Design & Visuels
- **Palette Rouge-Noir Futuriste**: Canvas soigneusement ajusté avec `#0a0202` et éclats rouge néon, typographie cyber Orbitron.
- **Navbar Flottante en Verre**: Navigation moderne avec `backdrop-blur-2xl`, déclencheurs CTA rapides et tiroir mobile.
- **Canvas Particules Cyber 60fps**: Rendu canvas HTML5 avec nœuds lumineux interactifs connectés par des fils de constellation réactifs.
- **Cartes Spotlight Suivant la Souris**: Effets radiaux suivant le curseur inspirés de Linear/Vercel sur les modules de fonctionnalités et statistiques.
- **Marquee Communauté Discord**: Défilement automatique infini présentant de vraies communautés de serveurs vérifiées avec compteurs de membres en direct.

### ⚡ Centre d'Opérations Interactif
- **Sentinelle Anti-Nuke**: Radar de menaces simulé en direct et logs de restauration automatique.
- **Visualiseur Audio Hi-Fi 384kbps**: Ondes sonores d'égaliseur animées, scrubbers de piste en direct et bascules de préréglages audio.
- **Terminal Slash Interactif**: Commandes Discord préréglées cliquables (`/antinuke setup`, `/ban`, `/play`) qui simulent des réponses bot en direct.
- **Télémétrie Cluster**: Débit en temps réel, santé des shards et graphiques d'activité wave 24h.

### 🗂️ Architecture Modale Ultra-Propre à la Demande
Le contenu volumineux est organisé dans des modales en verre givré à la demande pour garder la page d'accueil ultra-rapide et épurée :
- **`CommandsModal`**: Recherche instantanée parmi 34+ commandes slash avec filtres de catégorie et copie syntaxe en 1-clic avec feedback visuel `Copié! ✓`.
- **`PricingModal`**: 3 niveaux transparents (Gratuit, Premium avec surbrillance lumineuse, Entreprise), listes de fonctionnalités et CTAs d'invitation Discord.
- **`FAQModal`**: Accordéon FAQ avec recherche en temps réel, questions pliables et passerelle de support Discord 24/7.
- **`Documentation`**: Guides complets étape par étape organisés par catégories (Modération, Musique, Économie, etc.).

## 🚀 Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/MohsinAli088/Fluorine-landing-page.git
cd Fluorine-landing-page
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### 4. Build for Production
```bash
npm run build
```

## 📦 Deploy to Vercel

The easiest way to deploy this Next.js app is to use the [Vercel Platform](https://vercel.com/new):

1. Push this repository to your GitHub account.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Click **"Deploy"** (Next.js preset is automatically detected).

Zero database or build-step configuration required!
